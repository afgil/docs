---
title: "Estado del Enrolamiento"
openapi: "GET /credentials/enrollments/{enrollment_id}"
---

## Que hace

- Devuelve el estado del enrolamiento iniciado con `POST /credentials`
- Entrega la credencial cuando el SII ya validó la clave
- Distingue una clave rechazada por el SII de una falla temporal reintentable

## Por que existe

El login contra el SII se hace con un navegador real, fuera del request HTTP.
Por eso `POST /credentials` no puede devolver la credencial: responde `202` con
un `enrollment_id` y este endpoint entrega el resultado cuando está listo.

## Estados

| `status` | Significado | Que hacer |
|----------|-------------|-----------|
| `pending` | El login contra el SII sigue en curso | Volver a consultar en 2-3 segundos |
| `valid` | La credencial quedó enrolada | Leer `credential` en la respuesta |
| `invalid` | El SII rechazó la clave | Mostrar `error` al usuario y pedir la clave de nuevo |
| `error` | No se pudo preguntarle al SII (falla temporal) | Reintentar el enrolamiento más tarde; la clave NO fue rechazada |

## Cuanto tarda

El login demora del orden de **15 segundos**. Consultar cada 2-3 segundos es
suficiente; no es necesario consultar más seguido.

## Ejemplo

```bash
curl https://api.tupana.ai/v1/credentials/enrollments/cenr_3940730445066399260/ \
  -H "Authorization: Api-Key TU_API_KEY"
```
