Cada error de la API trae un `code` estable y un `doc_url` que lleva a la página de ese código. Aquí están todos. El formato de la respuesta está en [Errores](/api-reference/v2/errors).

### Autenticación y permisos

| Código | Qué significa | HTTP | ¿Reintentar? |
|--------|---------------|:----:|:------------:|
| [`unauthenticated`](/api-reference/errors/unauthenticated) | Falta la API key | 403, 401, 422 | No |
| [`forbidden`](/api-reference/errors/forbidden) | Sin acceso | 403, 401, 422 | No |
| [`sandbox_read_only`](/api-reference/errors/sandbox_read_only) | Operación no disponible con una key de sandbox | 403 | No |
