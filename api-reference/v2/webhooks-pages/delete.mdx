---
title: 'Eliminar un webhook (API v2)'
sidebarTitle: 'Eliminar webhook'
description: 'Elimina un webhook de Tupana para dejar de recibir eventos.'
openapi: 'api-reference/openapi-v2.json DELETE /webhooks/{webhook_id}/'
---

Elimina el webhook. Las entregas ya registradas se conservan para auditoría. Para pausarlo sin borrarlo usa `PATCH` con `{"is_active": false}`.
