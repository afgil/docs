---
title: "Obtener un estado de cuenta de tarjeta"
openapi: "api-reference/openapi-v2.json GET /card-statements/{card_statement_id}/"
---

Un estado de cuenta de tarjeta por su id (`cstm_…`), con la misma forma que en
[el listado](/api-reference/v2/card-statements/list) más sus líneas en
`movements`. Cada línea es un [movimiento de tarjeta](/api-reference/v2/card-movements/get)
completo, con `statement_id` apuntando a este estado de cuenta.

```bash
curl https://api.tupana.ai/v2/card-statements/cstm_Rb5829104736251/ \
  -H "Authorization: Api-Key TU_API_KEY"
```
