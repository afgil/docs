# Consultas

Los endpoints de **Consultas** te dan lectura del estado tributario de una
entidad, sin emitir nada:

- **Libros SII** — el resumen del Registro de Compras y Ventas (RCV) del SII
  por período (`book-summaries`) y su detalle documento por documento
  (`book-documents`).
- **Sincronización** — dispara y consulta la sincronización de datos con el SII
  (`sync-requests`, `sync-status`).
- **Folios** — disponibilidad y solicitudes de folios (CAF), y consultas de
  folios ya usados.

<Note>
Todos los identificadores son **public IDs** con prefijo (`ment_…`, `docu_…`,
`syre_…`, `fir_…`, `foqu_…`). Las respuestas de lista usan el envelope único
`{ data, meta, links }`.
</Note>
