---
title: "Recomendaciones de un movimiento"
openapi: "api-reference/openapi-v2.json GET /movements/{movement_id}/reconciliation-suggestions/"
---

Las recomendaciones de conciliación de un movimiento (`move_…`), con el mismo
envelope `{data, meta, links}` que [el listado](/api-reference/v2/reconciliation-suggestions/list).
Acepta los filtros `since` y `status` y pagina con `page` y `page_size`.

```bash
curl https://api.tupana.ai/v2/movements/move_Qm8102938475612/reconciliation-suggestions/ \
  -H "Authorization: Api-Key TU_API_KEY"
```

Si las recomendaciones no están activas en la conexión de esa empresa,
responde `403` con `code: "addon_required"`. Si el movimiento no existe para tu
API key, `404` con `code: "not_found"`. Los errores vienen en el
[formato de la API v2](/api-reference/v2/errors).
