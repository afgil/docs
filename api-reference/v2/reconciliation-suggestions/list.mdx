---
title: "Listar recomendaciones de conciliación"
openapi: "api-reference/openapi-v2.json GET /reconciliation-suggestions/"
---

Las recomendaciones de conciliación de una empresa: para cada movimiento, qué
documentos emitidos o recibidos concilia, con su `type` y su `score`. Lee
[Recomendaciones de conciliación](/api-reference/v2/banking/guides/reconciliation-suggestions)
para activarlas y entender cada campo.

```bash
curl "https://api.tupana.ai/v2/reconciliation-suggestions/?company_id=ment_3672486436546233854&status=suggested&page_size=100" \
  -H "Authorization: Api-Key TU_API_KEY"
```

Las más nuevas primero. Filtra por `company_id`, `account_id`, `movement_id`,
`since` (fecha de creación de la recomendación; con una key de sandbox, fecha
del movimiento) y `status` (`suggested`, `applied`, `discarded`). Sin
`company_id`, trae las de todas las empresas de tu key con el adicional activo.

La respuesta usa el mismo envelope que el resto de los listados v2:

```json
{
  "data": [ { "id": "brr_8810293746521", "type": "perfect", "score": 96, "status": "suggested", "...": "..." } ],
  "meta": { "page": 1, "page_size": 50, "total": 1, "total_pages": 1 },
  "links": { "next": null, "prev": null }
}
```

Pagina con `page` y `page_size` (máximo 200).

Si las recomendaciones no están activas, responde `403` con
`code: "addon_required"` en el [formato de error v2](/api-reference/v2/errors).
