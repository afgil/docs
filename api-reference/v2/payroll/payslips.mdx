## Obtener liquidación

`GET /api/v2/payroll/payslips/{id}/`

Retorna el detalle completo de una liquidación individual, incluyendo
todas las líneas (haberes, descuentos, aportes).

### Path params

| Parámetro | Tipo | Descripción |
|-----------|------|-------------|
| `id` | string | Public ID de la liquidación (`slip_...`) |

### Ejemplo cURL

```bash
curl -H "Authorization: Api-Key TU_API_KEY" \
  "https://api.tupana.ai/api/v2/payroll/payslips/slip_7291048302917/"
```

## Compatibilidad

El `id` legacy (entero) también es aceptado:

```bash
# Ambas requests retornan lo mismo
curl ".../payslips/slip_7291048302917/"
curl ".../payslips/7291048302917/"
```
