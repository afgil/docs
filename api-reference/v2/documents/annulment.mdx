Una factura emitida no se borra del SII: se anula emitiendo una **nota de crédito** que la referencia con el código 1 del SII, "Anula documento de la referencia". Con `POST /v2/documents/actions/batch/` y la acción **`annul_with_credit_note`**, Tupana arma esa nota de crédito copiando el receptor y las líneas del documento original, la emite en el SII y te la devuelve con su folio.

## Qué se puede anular

| Documento original | Se anula con |
|---|---|
| Factura electrónica (33), factura exenta (34) | Nota de crédito (61) |
| Boleta (39), boleta exenta (41) | Nota de crédito (61) |
| Factura de compra (46) | Nota de crédito (61) |
| Factura de exportación (110) | Nota de crédito de exportación (112) |
| Boleta de honorarios (80) | Sin nota de crédito: se anula directo en el SII. Ver [Anular boleta de honorarios](/api-reference/v2/honorary/annulment). |

El documento tiene que estar emitido, con folio. Un borrador no llegó al SII y no hay nada que anular.

## Request

```json
{
  "action_type": "annul_with_credit_note",
  "document_ids": ["docu_1234567890123456789"]
}
```

| Campo | Qué es |
|---|---|
| `action_type` | Siempre `"annul_with_credit_note"`. |
| `document_ids` | Los `id` de los documentos a anular, los mismos que devuelve la [emisión](/api-reference/v2/documents/batch) o [`GET /v2/documents/`](/api-reference/v2/documents/list). Puedes enviar varios. |
| `reference_reason` | Opcional. La razón que va en la referencia de la nota de crédito. Por defecto, `ANULA DOCUMENTO DE LA REFERENCIA`. |
| `date_issued` | Opcional. Fecha de emisión de la nota de crédito (`AAAA-MM-DD`). Por defecto, hoy. |

## Respuesta

`201` con una nota de crédito emitida por cada documento anulado:

```json
{
  "results": [
    {
      "id": "docu_9876543210987654321",
      "folio": "245",
      "date_issued": "2026-11-11",
      "state": "issued",
      "dte_type": { "code": "61", "name": "Nota de Crédito Electrónica" }
    }
  ]
}
```

Si algunos documentos no se pudieron anular, vienen en `partial_errors` con su `document_id` y el motivo; los demás se anulan igual. Si no se pudo anular ninguno, responde `400` con el detalle de cada uno.

<Note>
La nota de crédito es un documento más: la consultas con [`GET /v2/documents/{id}/`](/api-reference/v2/documents/get), con su PDF y XML, y te llegan los mismos webhooks que en una emisión.
</Note>
