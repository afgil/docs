# Códigos de retención de IVA en la factura de compra

Algunos productos tienen **cambio de sujeto de IVA**: el comprador (agente retenedor) emite una
factura de compra (DTE 46) y retiene todo o parte del IVA. Por ejemplo, en la compra de berries el
comprador retiene el **14%** y el vendedor declara y paga el **5%** restante.

Con la API indicas el producto y su código de retención en cada línea de `details`:

| Campo | Valor |
|---|---|
| `item_type_code` | `"CPCS"` (Código de Producto de Cambio de Sujeto) |
| `item_code` | El código del producto de la tabla de abajo, p. ej. `"4801"` |
| `unit` | Una de las unidades permitidas para ese producto, p. ej. `"KG"` |
| `vat_withholding_code` | El código de retención: el **parcial** del rubro (p. ej. `"48"`) o el **total** (p. ej. `"481"`) |

<Warning>
**Requiere autorización del SII.** Solo puede usar estos códigos una empresa que tenga la calidad
de **agente retenedor** del producto. Tupana no conoce esa calidad: si la empresa no la tiene, el
SII rechaza el documento. Confírmala con tu contador o en el SII antes de emitir.
</Warning>

<Note>
**Si no envías `vat_withholding_code`, nada cambia:** la línea retiene el IVA completo con el
código genérico `15`, como siempre, aunque traiga un producto de la tabla. La retención por
producto solo se activa cuando envías el código.
</Note>

## Dónde aplica

- **Factura de compra (DTE 46)** con `header.vat_withheld: true`.
- **Notas de crédito y débito (DTE 61 / 56) que referencian una factura de compra.** Envía en
  sus líneas el mismo producto y código que la factura original (no se heredan).
- Funciona igual con el **facturador de mercado** y con el **facturador gratuito del SII (MiPyme)**.
- Es un campo **solo de la API**: no está en la plataforma web ni en el MCP.

## Retención parcial o total

Cada rubro con retención parcial tiene dos códigos:

- **Parcial** (2 dígitos, p. ej. `48`): el comprador retiene la tasa del rubro (14% en berries) y el
  resto del IVA (`IVANoRet`) lo declara y paga el vendedor.
- **Total** (3 dígitos, p. ej. `481`): el comprador retiene el IVA completo (19%). Corresponde, entre
  otros, cuando el vendedor está en la **Nómina de Difícil Fiscalización** o en la **Nómina de
  Contribuyentes Sujetos a Retención**, o es una persona natural agricultora que no emite factura
  (para berries, Res. Ex. SII N° 11 de 2025).

Los rubros de la segunda tabla solo admiten retención total y su único código es el del rubro.

## Ejemplo: compra de frambuesa fresca con retención del 14%

```json
{
  "documents": [
    {
      "dte_type": { "code": "46" },
      "date_issued": "2026-11-23",
      "document_issuer": { "rut": "76.111.111-1" },
      "document_receiver": {
        "rut": "12.345.678-5",
        "business_name": "Productor Agrícola",
        "business_activity": "Cultivo de frutas",
        "address": "Fundo Los Robles s/n",
        "district": "Linares",
        "city": "Linares"
      },
      "header": { "purchase_transaction_type": 1, "vat_withheld": true },
      "details": [
        {
          "item_name": "Frambuesa fresca",
          "item_type_code": "CPCS",
          "item_code": "4801",
          "unit": "KG",
          "quantity": 100,
          "unit_price": 1000,
          "vat_withholding_code": "48"
        }
      ]
    }
  ]
}
```

Montos del documento:

| Concepto | Monto |
|---|---|
| Neto | $100.000 |
| IVA (19%) | $19.000 |
| IVA retenido por el comprador (código 48, 14%) | $14.000 |
| IVA no retenido (lo paga el vendedor, 5%) | $5.000 |
| **Total** (neto + IVA no retenido) | **$105.000** |

Con `"vat_withholding_code": "481"` el comprador retiene los $19.000 y el total es $100.000.

## Errores de validación

Se responden con `422` antes de crear el documento, bajo `documents.<posición>.<campo>` (no se
emite nada ni se consume folio). Por ejemplo:

```json
{
  "documents": {
    "0": {
      "unit": ["Línea 1: El producto 4801 (Frambuesa fresca) se informa en KG; se recibió 'UN'."]
    }
  }
}
```


| Caso | Campo | Mensaje (ejemplo) |
|---|---|---|
| Código en un documento que no es factura de compra ni nota de una | `vat_withholding_code` | `vat_withholding_code sólo aplica a la factura de compra (46) y a sus notas de crédito y débito.` |
| Producto que no está en la tabla o sin `item_type_code: "CPCS"` | `vat_withholding_code` | `vat_withholding_code requiere item_type_code 'CPCS' y un item_code de la tabla de productos con cambio de sujeto.` |
| Código de otro rubro | `vat_withholding_code` | `Línea 1: El producto 4801 (Berries) admite vat_withholding_code 48 o 481; se recibió '361'.` |
| Unidad no permitida | `unit` | `Línea 1: El producto 4801 (Frambuesa fresca) se informa en KG; se recibió 'UN'.` |
| Línea exenta con código | `is_exempt` | `Línea 1: El producto 4801 (Frambuesa fresca) tiene retención de IVA: la línea no puede ser exenta.` |
