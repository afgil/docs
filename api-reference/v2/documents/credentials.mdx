## Listar credenciales

`GET /v2/credentials/`

### Query params

| Parámetro | Tipo | Requerido | Descripción |
|-----------|------|-----------|-------------|
| `master_entity_id` | string | ✓ | Public ID de la empresa (`ment_...`) |

### Respuesta

```json
[
  {
    "id": "cred_5028174639201",
    "master_entity_id": "ment_4829301923847",
    "credential_type": "SII",
    "status": "VALID",
    "created_at": "2024-01-15T10:00:00Z"
  }
]
```

### Ejemplo cURL

```bash
curl -H "Authorization: Api-Key TU_API_KEY" \
  "https://api.tupana.ai/v2/credentials/?master_entity_id=ment_4829301923847"
```

## Crear credencial

`POST /v2/credentials/`

### Body

```json
{
  "master_entity_id": "ment_4829301923847",
  "credential_type": "SII",
  "rut": "76.111.222-3",
  "password": "mi_clave_sii"
}
```

### Respuesta

```json
{
  "id": "cred_5028174639201",
  "master_entity_id": "ment_4829301923847",
  "credential_type": "SII",
  "status": "VALID",
  "created_at": "2024-08-15T12:00:00Z"
}
```
