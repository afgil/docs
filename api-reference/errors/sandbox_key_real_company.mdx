## Qué significa

**Key de sandbox con una empresa real.** Una API key de sandbox solo ve tu Empresa Demo, y la solicitud nombra una empresa real.

## Causas posibles

- Se usó una key de sandbox con el id de una empresa real.
- El id de la empresa quedó de una prueba anterior en producción.

## Cómo resolverlo

- Para tu empresa real, usa una API key de producción.
- Para seguir probando, usa el id de tu Empresa Demo.

## ¿Conviene reintentar?

No. Repetir la misma solicitud va a fallar igual: primero hay que corregir la causa.
