## Qué significa

**El documento no se puede cobrar.** Ese tipo de documento, o su estado, no admite un cobro.

## Causas posibles

- El documento es de un tipo que no se cobra.
- El documento fue anulado.

## Cómo resolverlo

- Usa una factura o boleta vigente.

## ¿Conviene reintentar?

No. Repetir la misma solicitud va a fallar igual: primero hay que corregir la causa.
