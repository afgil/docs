## Qué significa

**Demasiadas solicitudes.** Superaste el límite de solicitudes de tu cuenta para ese período.

## Causas posibles

- Un ciclo consulta sin pausas.
- Varios procesos comparten la misma API key.

## Cómo resolverlo

- Espera los segundos del header Retry-After y reintenta.
- Reintenta con esperas crecientes.
- Usa webhooks en vez de consultar el estado una y otra vez.

## ¿Conviene reintentar?

Sí. Reintenta, aumentando la espera en cada intento.
