## Qué significa

**Solicitud inválida.** No pudimos leer la solicitud.

## Causas posibles

- El cuerpo no es JSON válido.
- Falta el header Content-Type: application/json.

## Cómo resolverlo

- Valida que el cuerpo sea JSON bien formado.
- Envía el header Content-Type: application/json.

## ¿Conviene reintentar?

No. Repetir la misma solicitud va a fallar igual: primero hay que corregir la causa.
