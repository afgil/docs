## Qué significa

**El recurso no existe.** No existe un recurso con ese id, o no pertenece a tu cuenta.

## Causas posibles

- El id quedó mal copiado.
- El recurso es de otra empresa o de otra cuenta.
- El id es de sandbox y la key de producción, o al revés.

## Cómo resolverlo

- Verifica el id (viene en resource cuando lo conocemos).
- Lista los recursos de esa ruta para confirmar que existe.

## ¿Conviene reintentar?

No. Repetir la misma solicitud va a fallar igual: primero hay que corregir la causa.
