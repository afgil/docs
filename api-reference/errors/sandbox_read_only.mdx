## Qué significa

**Operación no disponible con una key de sandbox.** Con una API key de sandbox las conexiones de empresas son de solo lectura.

## Causas posibles

- Se intentó desactivar o reautorizar una conexión con una key de sandbox.

## Cómo resolverlo

- Repite la operación con una API key de producción.

## ¿Conviene reintentar?

No. Repetir la misma solicitud va a fallar igual: primero hay que corregir la causa.
