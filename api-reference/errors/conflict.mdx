## Qué significa

**Conflicto con datos existentes.** La operación choca con algo que ya existe o con el estado actual del recurso.

## Causas posibles

- Ya existe un recurso con esos mismos datos únicos.
- Dos solicitudes iguales llegaron al mismo tiempo.

## Cómo resolverlo

- Consulta el recurso para ver su estado actual antes de reintentar.
- Usa una llave de idempotencia para no crear duplicados.

## ¿Conviene reintentar?

No. Repetir la misma solicitud va a fallar igual: primero hay que corregir la causa.
