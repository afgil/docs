## Qué significa

**Falta la API key.** La solicitud llegó sin una API key que podamos leer.

## Causas posibles

- No se envió el header Authorization.
- El header no tiene el formato Api-Key &lt;tu_api_key&gt;.
- Un proxy o intermediario quitó el header antes de llegar a Tupana.

## Cómo resolverlo

- Envía el header Authorization: Api-Key &lt;tu_api_key&gt; en cada solicitud.
- Revisa que no haya espacios ni comillas de más en la key.
- Si usas un proxy, confirma que reenvía el header Authorization sin cambios.

## ¿Conviene reintentar?

No. Repetir la misma solicitud va a fallar igual: primero hay que corregir la causa.
