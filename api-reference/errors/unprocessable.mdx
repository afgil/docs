## Qué significa

**No se puede procesar.** La solicitud está bien formada, pero no cumple una regla del documento o de la operación.

## Causas posibles

- Los datos se contradicen entre sí.
- La operación no aplica a ese tipo de documento.

## Cómo resolverlo

- Lee el mensaje: dice qué regla no se cumple.
- Ajusta los datos y reenvía.

## ¿Conviene reintentar?

No. Repetir la misma solicitud va a fallar igual: primero hay que corregir la causa.
