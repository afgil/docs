## Qué significa

**Cursor inválido.** El cursor de paginación no es uno que hayamos emitido.

## Causas posibles

- El cursor fue modificado o quedó cortado.
- Se usó el cursor de otra ruta.

## Cómo resolverlo

- Usa tal cual el next_cursor de la respuesta anterior.
- Si lo perdiste, parte de nuevo sin cursor.

## ¿Conviene reintentar?

No. Repetir la misma solicitud va a fallar igual: primero hay que corregir la causa.
