## Qué significa

**Sin acceso.** La API key no puede hacer esta operación o no tiene acceso a esta empresa.

## Causas posibles

- La API key fue desactivada o eliminada.
- La key no existe (por ejemplo, quedó mal copiada).
- La key es de sandbox y la ruta es de producción, o al revés.
- La empresa indicada no está conectada a tu cuenta.

## Cómo resolverlo

- Revisa en la consola que la key esté activa y cópiala de nuevo.
- Usa la key del ambiente correcto: sandbox para pruebas, producción para documentos reales.
- Confirma que la empresa esté conectada a tu cuenta en la consola.

## ¿Conviene reintentar?

No. Repetir la misma solicitud va a fallar igual: primero hay que corregir la causa.
