## Qué significa

**Sesión del SII vencida.** La sesión con el SII se cerró y la estamos abriendo de nuevo.

## Causas posibles

- El SII cierra las sesiones cada cierto tiempo.

## Cómo resolverlo

- Reintenta en unos segundos.

## ¿Conviene reintentar?

Sí. Espera al menos 15 segundos y reintenta; si el error sigue, aumenta la espera en cada intento.
