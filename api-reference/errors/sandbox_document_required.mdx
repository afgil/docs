## Qué significa

**Ambiente del documento incorrecto.** El documento y la API key no son del mismo ambiente.

## Causas posibles

- Se usó un documento real con una key de sandbox, o al revés.

## Cómo resolverlo

- Usa documentos del mismo ambiente que la API key.

## ¿Conviene reintentar?

No. Repetir la misma solicitud va a fallar igual: primero hay que corregir la causa.
