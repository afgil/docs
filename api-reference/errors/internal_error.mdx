## Qué significa

**Error interno.** Algo falló del lado de Tupana. No es un problema de tu solicitud.

## Causas posibles

- Un error nuestro.

## Cómo resolverlo

- Reintenta con la misma llave de idempotencia.
- Si persiste, escríbenos con el request_id.

## ¿Conviene reintentar?

Sí. Reintenta, aumentando la espera en cada intento.
