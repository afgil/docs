## Qué significa

**No encontrado.** La ruta o el recurso no existe.

## Causas posibles

- La URL tiene un error o le falta la barra final.
- El id no existe o es de otra cuenta.
- El id es de sandbox y la key de producción, o al revés.

## Cómo resolverlo

- Revisa la URL contra la referencia.
- Confirma que el id exista y sea del mismo ambiente que la key.

## ¿Conviene reintentar?

No. Repetir la misma solicitud va a fallar igual: primero hay que corregir la causa.
