# Autenticación

Para comenzar a utilizar la API de Tupana, necesitarás configurar la autenticación correctamente. Utilizamos un sistema de API Keys para garantizar la seguridad de tus transacciones.

## Obtener tu API Key

1. Entra a [developers.tupana.ai/console](https://developers.tupana.ai/console) (o, si usas la plataforma, a **Configuración → API Keys**).
2. Crea una nueva API key. Las keys nuevas **nacen en modo sandbox**: simulan la emisión y no envían nada al SII.
3. Guarda tu API key en un lugar seguro: no podrás verla nuevamente.

### Sandbox y producción

| | Sandbox | Producción |
|---|---|---|
| Emisión | Simulada: el documento se crea con folio `SANDBOX-{n}` y no va al SII | Real, al SII |
| Datos | Nunca toca datos reales | Tus empresas conectadas |
| Costo | Gratis | Según [Precios](/precios) |

### Permisos

Cada API key tiene permisos por alcance, por ejemplo `document:access` (leer documentos), `document:create` (emitir), `master_entity:access` (buscar entidades) y `book_summary:access` (libros del SII). Una key con `*` tiene todos. Usa el mínimo que necesite cada integración, sobre todo si la usa un [agente de IA](/agentes/introduccion).

## Usar tu API Key

### Headers de Autenticación

Para autenticarte con la API, incluye tu API Key en el header de tus peticiones usando el prefijo `Api-Key`:

```bash
curl -X POST https://api.tupana.ai/v2/documents/batch/ \
  -H "Authorization: Api-Key TU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"documents": [ ... ]}'
```

### Ejemplo en Python

```python
import requests

api_key = "tu_api_key"
headers = {
    "Authorization": f"Api-Key {api_key}",
    "Content-Type": "application/json"
}

response = requests.post(
    "https://api.tupana.ai/v2/documents/batch/",
    headers=headers,
    json={"documents": [...]}
)
```

## Seguridad

### Mejores Prácticas

1. **Nunca compartas tu API Key**
2. Rota tus API Keys regularmente
3. Utiliza diferentes API Keys para producción y desarrollo
4. Monitorea el uso de tus API Keys

### Manejo de Errores

Si recibes un error de autenticación (401), verifica:

1. Que estás usando la API Key correcta
2. Que la API Key no ha expirado
3. Que el formato del header es correcto (debe ser `Authorization: Api-Key TU_API_KEY`)
4. Que la API Key está activa en tu panel de control
