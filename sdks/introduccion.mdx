Tupana tiene clientes oficiales para Node.js (TypeScript) y Python, con código abierto en GitHub.

| Lenguaje | Repositorio | Instalación hoy | Paquete |
|---|---|---|---|
| Node.js / TypeScript | [tupana-ai/tupana-node](https://github.com/tupana-ai/tupana-node) | `npm i github:tupana-ai/tupana-node` | `@tupana-ai/sdk` en npm (próximamente) |
| Python | [tupana-ai/tupana-python](https://github.com/tupana-ai/tupana-python) | `pip install git+https://github.com/tupana-ai/tupana-python` | `tupana` en PyPI (próximamente) |

<Note>
Mientras los paquetes no estén publicados en npm y PyPI, instala desde GitHub con los comandos de la tabla. Cuando se publiquen, bastará con `npm i @tupana-ai/sdk` o `pip install tupana`. La API del cliente y sus ejemplos están en el README de cada repositorio.
</Note>

## Instalación

<CodeGroup>

```bash Node.js
npm i github:tupana-ai/tupana-node
```

```bash Python
pip install git+https://github.com/tupana-ai/tupana-python
```

</CodeGroup>

Guarda tu API key en una variable de entorno (por ejemplo `TUPANA_API_KEY`) y pásasela al cliente desde ahí; nunca la dejes en el código. Para obtener una, ver [Tu primera llamada en 2 minutos](/quickstart).

## Sin SDK: la API REST directa

La API es REST con JSON, así que cualquier cliente HTTP sirve. Lo único que necesitas es el header `Authorization: Api-Key <tu_key>`.

<CodeGroup>

```javascript Node.js (fetch)
const res = await fetch("https://api.tupana.ai/v2/documents/batch/", {
  method: "POST",
  headers: {
    Authorization: `Api-Key ${process.env.TUPANA_API_KEY}`,
    "Content-Type": "application/json",
    "Idempotency-Key": "pedido-1001",
    "X-Use-Defaults": "true",
  },
  body: JSON.stringify({
    documents: [{
      dte_type: { code: "33" },
      document_issuer: { rut: "76123456-7" },
      document_receiver: { rut: "77987654-3", business_name: "Cliente SpA" },
      details: [{ item_name: "Servicio", quantity: 1, unit_price: 100000 }],
    }],
  }),
});
console.log(res.status, await res.json());
```

```python Python (requests)
import os, requests

res = requests.post(
    "https://api.tupana.ai/v2/documents/batch/",
    headers={
        "Authorization": f"Api-Key {os.environ['TUPANA_API_KEY']}",
        "Idempotency-Key": "pedido-1001",
        "X-Use-Defaults": "true",
    },
    json={
        "documents": [{
            "dte_type": {"code": "33"},
            "document_issuer": {"rut": "76123456-7"},
            "document_receiver": {"rut": "77987654-3", "business_name": "Cliente SpA"},
            "details": [{"item_name": "Servicio", "quantity": 1, "unit_price": 100000}],
        }]
    },
)
print(res.status_code, res.json())
```

</CodeGroup>

## Genera tu propio cliente
